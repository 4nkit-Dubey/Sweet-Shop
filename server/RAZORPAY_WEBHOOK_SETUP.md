# Razorpay webhook setup

Add the webhook secret generated by the Razorpay Dashboard to `server/.env`:

```env
RAZORPAY_WEBHOOK_SECRET=your_dashboard_webhook_secret
```

In Razorpay Dashboard, register a webhook at:

```text
https://<your-public-api-host>/api/order/razorpay/webhook
```

Subscribe to `payment.captured` and `order.paid`. Use the same webhook secret
in the Dashboard and `RAZORPAY_WEBHOOK_SECRET`. The webhook endpoint verifies
the signature against the raw request body, so any proxy in front of the API
must forward the request body unchanged.

For local development, expose the API through a trusted HTTPS tunnel and use
that public URL as the webhook URL. A localhost URL cannot receive Razorpay
webhook deliveries.
